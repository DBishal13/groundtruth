groundtruth

LangGraph for GIS — an open, model-agnostic validation layer that catches an LLM's bad CRS, geometry, and topology before it reaches your GIS pipeline.

Esri, Google, and CARTO are each building this feature into their own walled platform. Nobody's shipped it as a portable, open primitive any agent stack can drop in — over MCP, LangGraph, or a raw tool-calling loop. This is the bet that it should exist as infrastructure, not a vertical app.

Why this matters

The gap is real, and closing

Esri ships AI Assistants into ArcGIS Online on a monthly cadence through 2026. Google Research's "Geospatial Reasoning" orchestrates Gemini across multiple Earth foundation models, still a trusted-tester preview. CARTO ships production AI agents over customer warehouses.

All three are building the same underlying safeguard — catch the model's bad geometry before it reaches real GIS work — inside their own platform. None of them ship it as something a Claude, LangGraph, or custom agent stack outside their walls can use.

GeoBenchX: even the best model tested (Claude Sonnet 3.5) hit only 53% success on solvable multi-step geospatial tasks — routinely confusing centroids for polygons and using stale geographic facts.

Architecture

Two paths, one validation core

An LLM either passes geometry inline in a tool-call argument, or points at a file it can't embed (Shapefile, GeoPackage). Both roads run through the same structural, topology, and CRS checks.

Both paths share the same structural + topology + CRS checks — the only difference is how many features go through them at once.

Get started

Three ways in

As a library
// not yet on npm — clone and link locally
git clone github.com/DBishal13/groundtruth
cd groundtruth && npm install && npm run build

// then, in your agent's tool layer:
import { guardToolCall } from "groundtruth";
const result = guardToolCall({ geometry });
As an MCP server
claude mcp add groundtruth -- \
  node dist/mcp/server.js

// exposes: validate_geometry,
// validate_geometry_file, buffer_geometry,
// reproject_geometry, intersect_geometries
